### **Middleware :**

**sits between client and server and checks if the client is  a valid client**

There can be more than one middleware

runs on every request  from client to server to check security , authorization etc

THEY ARE BASICALLY FUNCTIONS THAT HAVE ACCESS TO **1: REQUEST OBJECT 2: RESPONSE OBJECT 3: AND TO NEXT MIDDLEWARE FUNCTION(OPTIONAL)**
